# VFS — Этап 1: REPL

## Описание

На первом этапе реализован минимальный прототип консольного интерфейса
(REPL — Read-Eval-Print Loop), позволяющий пользователю вводить команды
и получать результаты их выполнения. Команды работы с файловой системой являются заглушками.
Они не выполняют реальных операций, а только выводят имя команды и переданные
ей аргументы.

## Команды

### `ls`

Выводит название команды и переданные аргументы.

```text
my_vfs$ ls
ls

my_vfs$ ls -l /home
ls -l /home
```

### `cd`

Выводит название команды и переданные аргументы.

```text
my_vfs$ cd /home
cd /home
```

### `exit`

Завершает работу программы.

```text
my_vfs$ exit
Exiting program
```

Если передать аргументы:

```text
my_vfs$ exit test
ERROR: 'exit' command does not take any arguments!
```

### Неизвестная команда

```text
my_vfs$ mkdir test
ERROR: Unknown command 'mkdir'
```

## Запуск

```bash
python3 cmd_emu.py
```

или:

```bash
python cmd_emu.py
```

# VFS — Этап 2: Конфигурация эмулятора

## Описание

На втором этапе эмулятор виртуальной файловой системы (VFS) получил возможность принимать параметры командной строки и выполнять команды из стартового скрипта.

Команды работы с файловой системой пока остаются заглушками: они не выполняют реальных операций, а выводят имя команды и переданные аргументы.

## Поддерживаемые команды

### `ls`

Выводит название команды и переданные аргументы.

```text
my_vfs$ ls
ls

my_vfs$ ls -l /home
ls -l /home
```

### `cd`

Выводит название команды и переданные аргументы.

```text
my_vfs$ cd /home
cd /home
```

### `exit`

Завершает работу эмулятора, если команда вызвана без аргументов.

```text
my_vfs$ exit
Exiting program
```

Если передать аргументы, выводится сообщение об ошибке:

```text
my_vfs$ exit test
ERROR: 'exit' command does not take any arguments!
```

### Неизвестная команда

Для неизвестных команд выводится сообщение об ошибке.

```text
my_vfs$ mkdir test
ERROR: Unknown command 'mkdir'
```

## Параметры командной строки

Эмулятор принимает следующие обязательные параметры:

| Параметр | Описание |
|---|---|
| `--vfs` | Путь к физическому расположению виртуальной файловой системы |
| `--script` | Путь к стартовому скрипту с командами эмулятора |

При запуске эмулятор выводит переданные параметры в отладочном режиме.

Пример запуска:

```bash
python src/cmd_emu.py --vfs "./vfs" --script "./scripts/startup.txt"
```

Также можно использовать команду `py` или `python3` в зависимости от установленной среды Python.

## Стартовый скрипт

Стартовый скрипт содержит команды, которые эмулятор выполняет последовательно при запуске.

Строки, начинающиеся с `#`, считаются комментариями. Пустые строки и комментарии пропускаются.

Пример `scripts/startup.txt`:

```text
# Проверка команд эмулятора
ls
ls -l /home
cd /home
exit
```

Во время выполнения скрипта эмулятор отображает команды и результаты их выполнения, имитируя ввод пользователя в консоли.

Если скрипт содержит команду `exit` без аргументов, работа эмулятора завершается после её выполнения.

## Запуск

В Windows можно запустить эмулятор с помощью файла `run.bat`, в котором указаны параметры командной строки.

Также запуск возможен напрямую:

```bash
python src/cmd_emu.py --vfs "./vfs" --script "./scripts/startup.txt"
```
