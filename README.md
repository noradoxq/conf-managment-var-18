# VFS — Этап 1: REPL

## Описание

На первом этапе реализован минимальный прототип консольного интерфейса
(REPL — Read-Eval-Print Loop), позволяющий пользователю вводить команды
и получать результаты их выполнения. Команды работы с файловой системой являются заглушками.
Они не выполняют реальных операций, а только выводят имя команды и переданные
ей аргументы.

## Команды

### `ls`

Выводит название команды и переданные аргументы.

```text
my_vfs$ ls
ls

my_vfs$ ls -l /home
ls -l /home
```

### `cd`

Выводит название команды и переданные аргументы.

```text
my_vfs$ cd /home
cd /home
```

### `exit`

Завершает работу программы.

```text
my_vfs$ exit
Exiting program
```

Если передать аргументы:

```text
my_vfs$ exit test
ERROR: 'exit' command does not take any arguments!
```

### Неизвестная команда

```text
my_vfs$ mkdir test
ERROR: Unknown command 'mkdir'
```

## Запуск

```bash
python3 cmd_emu.py
```

или:

```bash
python cmd_emu.py
```

## Структура проекта

```text
.
├── src/
│   └── cmd_emu.py
├── tests/
│   └── .gitkeep
├── .gitignore
├── README.md
└── run.bat
```

# VFS — Этап 2: Конфигурация эмулятора

## Описание

На втором этапе эмулятор виртуальной файловой системы (VFS) получил возможность принимать параметры командной строки и выполнять команды из стартового скрипта.

Команды работы с файловой системой пока остаются заглушками: они не выполняют реальных операций, а выводят имя команды и переданные аргументы.

## Поддерживаемые команды

### `ls`

Выводит название команды и переданные аргументы.

```text
my_vfs$ ls
ls

my_vfs$ ls -l /home
ls -l /home
```

### `cd`

Выводит название команды и переданные аргументы.

```text
my_vfs$ cd /home
cd /home
```

### `exit`

Завершает работу эмулятора, если команда вызвана без аргументов.

```text
my_vfs$ exit
Exiting program
```

Если передать аргументы, выводится сообщение об ошибке:

```text
my_vfs$ exit test
ERROR: 'exit' command does not take any arguments!
```

### Неизвестная команда

Для неизвестных команд выводится сообщение об ошибке.

```text
my_vfs$ mkdir test
ERROR: Unknown command 'mkdir'
```

## Параметры командной строки

Эмулятор принимает следующие обязательные параметры:

| Параметр | Описание |
|---|---|
| `--vfs` | Путь к физическому расположению виртуальной файловой системы |
| `--script` | Путь к стартовому скрипту с командами эмулятора |

При запуске эмулятор выводит переданные параметры в отладочном режиме.

Пример запуска:

```bash
python src/cmd_emu.py --vfs "./vfs" --script "./scripts/startup.txt"
```

Также можно использовать команду `py` или `python3` в зависимости от установленной среды Python.

## Стартовый скрипт

Стартовый скрипт содержит команды, которые эмулятор выполняет последовательно при запуске.

Строки, начинающиеся с `#`, считаются комментариями. Пустые строки и комментарии пропускаются.

Пример `scripts/startup.txt`:

```text
# Проверка команд эмулятора
ls
ls -l /home
cd /home
exit
```

Во время выполнения скрипта эмулятор отображает команды и результаты их выполнения, имитируя ввод пользователя в консоли.

Если скрипт содержит команду `exit` без аргументов, работа эмулятора завершается после её выполнения.

## Запуск

В Windows можно запустить эмулятор с помощью файла `run.bat`, в котором указаны параметры командной строки.

Также запуск возможен напрямую:

```bash
python src/cmd_emu.py --vfs "./vfs" --script "./scripts/startup.txt"
```

```text
│   └── cmd_emu.py
├── tests/
│   └── .gitkeep
```

# VFS — Этап 3: Виртуальная файловая система

## Описание

На третьем этапе реализована виртуальная файловая система (VFS), которая загружает содержимое указанной физической директории в оперативную память.

Эмулятор позволяет просматривать содержимое каталогов, перемещаться между ними и получать текущий виртуальный путь. Все операции выполняются над моделью файловой системы в памяти, поэтому исходные файлы не изменяются во время работы программы.

Также реализована команда `vfs-save`, позволяющая сохранить текущее состояние виртуальной файловой системы в указанную физическую директорию.

## Поддерживаемые команды

### `ls`

Выводит название команды и переданные аргументы.

```text
my_vfs$ ls
ls

my_vfs$ ls -l /home
ls -l /home
```

### `cd`

Выводит название команды и переданные аргументы.

```text
my_vfs$ cd /home
cd /home
```

### `pwd`

Выводит текущий виртуальный путь.

```text
my_vfs$ pwd
/
my_vfs$ cd /home
Current directory: /home
my_vfs$ pwd
/home
```

### `vfs-save`

Сохраняет текущее состояние виртуальной файловой системы в указанную физическую директорию.

```text
my_vfs$ vfs-save ../vfs-output/saved
VFS saved to '../vfs-output/saved'
```

При сохранении восстанавливается структура каталогов и сохраняется содержимое файлов. Исходная директория VFS не должна изменяться.

Если путь не указан, выводится сообщение об ошибке:

```text
my_vfs$ vfs-save
ERROR: Usage: vfs-save <path>
```

### `exit`

Завершает работу эмулятора.

```text
my_vfs$ exit
Exiting program
```

Если передать аргументы:

```text
my_vfs$ exit test
ERROR: 'exit' command does not take any arguments!
```

### Неизвестная команда

Для неизвестных команд выводится сообщение об ошибке.

```text
my_vfs$ mkdir test
ERROR: Unknown command 'mkdir'
```

## Параметры командной строки

Эмулятор принимает следующие обязательные параметры:

| Параметр | Описание |
|---|---|
| `--vfs` | Путь к физической директории, содержимое которой загружается в VFS |
| `--script` | Путь к стартовому скрипту с командами эмулятора |

При запуске эмулятор выводит переданные параметры в отладочном режиме.

Пример запуска:

```bash
python src/cmd_emu.py --vfs "../vfs-data" --script "scripts/startup.txt"
```

Также можно использовать команды `py` или `python3` в зависимости от установленной среды Python.

## Стартовый скрипт

Стартовый скрипт содержит команды, которые эмулятор выполняет последовательно при запуске.

Строки, начинающиеся с `#`, считаются комментариями. Пустые строки и комментарии пропускаются.

Пример `scripts/startup.txt`:

```text
ls
ls -l
pwd

# exit
# ls
pwd

cd /
pwd
cd home
cd projects
pwd

ls
ls test.txt
ls missing.txt
ls app.py

cd missing_folder
unknown_command
cd home extra

cd /
pwd
ls
exit
```

Во время выполнения скрипта эмулятор отображает команды и результаты их выполнения, имитируя ввод пользователя в консоли.

Если скрипт содержит команду `exit` без аргументов, работа эмулятора завершается после её выполнения.

## Запуск

В Windows для запуска эмулятора используется файл `run.bat`.

Для интерактивной работы можно запустить эмулятор напрямую:

```bash
python src/cmd_emu.py --vfs "../vfs-data/several_files" --script "scripts/empty.txt"
```

После выполнения стартового скрипта эмулятор переходит в интерактивный режим, если выполнение не было завершено командой `exit`.

## Тестирование

Для запуска тестов используются файлы test_single_vfs.bat, test_triple_vfs.bat для Windows и test_vfs.sh для Linux/MacOS.

Тесты проверяют загрузку виртуальной файловой системы, просмотр каталогов, перемещение между ними, обработку ошибок и сохранение данных.


# VFS — Этап 4: Основные команды

## Описание

На данном этапе реализованы команды для работы с виртуальной файловой системой, имитирующие работу в UNIX-подобной командной строке.

## Реализованные команды

- `ls` — вывод содержимого текущей или указанной директории.
- `ls -l` — вывод содержимого в расширенном режиме.
- `cd <путь>` — переход в указанную директорию.
- `cd` — переход в корневую директорию VFS.
- `rev <файл>` — вывод строк файла в обратном порядке символов.
- `head <файл>` — вывод первых 10 строк файла.
- `head -n <число> <файл>` — вывод указанного количества строк файла.
- `clear` — очистка экрана терминала.

## Запуск программы

```bash
python src/cmd_emu.py --vfs "../vfs-data/data" --script "scripts/startup.txt"
```

Параметры запуска:

- `--vfs` — путь к физической директории, загружаемой в виртуальную файловую систему;
- `--script` — путь к стартовому скрипту с командами для проверки.

## Тестирование

В файле `scripts/startup.txt` содержатся примеры использования реализованных команд, включая различные режимы работы и обработку ошибок.

## Структура проекта

```text

│   └── startup.txt
├── src/
│   ├── cmd_emu.py
│   └── vfs.py
├── tests/
│   ├── test_single_vfs.bat
│   ├── test_triple_vfs.bat
│   └── test_vfs.sh

├── README.md
└── run.bat
```

# VFS — Этап 5: Управление файлами

## Описание

На данном этапе реализованы команды для копирования и удаления файлов и директорий в виртуальной файловой системе (VFS).

## Реализованные команды

- `ls` — вывод содержимого текущей или указанной директории.
- `ls -l` — вывод содержимого в расширенном режиме.
- `cd <путь>` — переход в указанную директорию.
- `cd` — переход в корневую директорию VFS.
- `rev <файл>` — вывод строк файла в обратном порядке символов.
- `head <файл>` — вывод первых 10 строк файла.
- `head -n <число> <файл>` — вывод указанного количества строк файла.
- `clear` — очистка экрана терминала.
- `cp <источник> <назначение>` — копирование файла в указанное место виртуальной файловой системы.
- `rm <путь>` — удаление файла.
- `rm -r <путь>` — рекурсивное удаление директории и её содержимого.
- `pwd` — вывод текущей директории VFS.
- `vfs-save` — сохранение изменений виртуальной файловой системы на физический диск.
- `exit` — завершение работы эмулятора.

## Запуск программы

```bash
python src/cmd_emu.py --vfs "../vfs-data/data" --script "scripts/startup.txt"
```

Параметры запуска:

- `--vfs` — путь к физической директории, загружаемой в виртуальную файловую систему;
- `--script` — путь к стартовому скрипту с командами для проверки.

## Тестирование

В файле `scripts/startup.txt` содержатся примеры использования реализованных команд, включая копирование и удаление файлов, обработку некорректных аргументов и ошибки при работе с несуществующими файлами.
